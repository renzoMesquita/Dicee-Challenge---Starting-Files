## Dicee Game Chalenge

This project was created using the Udemy course "The Complete Full-Stack Web Development Bootcamp," which teaches various programming languages ​​for web development.

In this project, two dice are rolled randomly, and it shows which of the two players won, or if they tied. A great alternative for those who are undecided and need to know who to listen to!!

## Contents
- Random number generation
- DOM manipulation
- JavaScript events
- Dynamic image changing
- Basic game logic

## Technology
- HTML
- CSS
- JavaScript

## Objective 
- Practice programming logic and DOM manipulation with JavaScript
